# 高精度下的分类器 recall 扫描（capture r1 特征）

复用 capture r1 已采集的第 32 层 hidden 和宽度 5/6/7/11 的原生单步反事实标签，没有重新运行 27B。比较了目标函数、MLP 深度、前一 token 第 32 层上下文、5 seed 集成，以及三种动作策略：

- `argmax`：当前部署方式，取 softmax 最大类并要求置信度达到阈值。
- `longest`：每个宽度的安全分数取 P(最长安全宽度 ≥ w)；五分类时为累计概率。选择达到阈值的最长宽度。
- `utility`：选择 `w·S_w − λ(1−S_w)` 最大的宽度，期望收益为正才跳。

配置和集成成员只按训练集内 10% 对话的 dev 选择。阈值在 calibration 上定，在 heldout 上报告；precision 区间为按对话 bootstrap 的 95% CI。反向（heldout 定阈、calibration 测试）结果见 summary。部署的五分类头用其保存的 cal99 阈值在 heldout 上逐项复现：accepted 2524、TP 2493、FP 31。

## 结论

1. **部署头过拟合。** dev 指标在第 2–3 轮最好，第 6 轮下降约 17%，24 轮后接近 0。早停的同结构头在 .995 目标下覆盖率 38.3%，部署头为 17.4%。
2. **策略影响很大。** argmax 置信度会把“跳 7 和跳 11 都安全”的概率拆到两个类里。改用累计概率后，同一个部署头在 .99 目标下覆盖率从 31.6% 升到 47.8%，precision 从 98.8% 升到 99.0%。
3. **只改头部的上限有限。** 在同一 .995 目标下，BCE/CE、焦点损失、负样本加权、线性/1×1024/2×2048、前一 token 上下文和 5 seed 集成在 heldout 上的平均省层都在 2.5–3.4 之间，差异与抽样噪声相当。只用第 32 层特征时，.995 precision 下大约省 3 层，约为 oracle 的 28%。
4. **on-policy 信号明显。** 前一 token 为模型自身 argmax 的位置，跳 11 层安全率为 93.7%，否则为 88.6%。在 .995 目标下，这两类位置的覆盖率分别为 39.3% 和 10.4%。训练标签来自数据集续写，而实际评测是模型自由生成。
5. 数学类数据覆盖率最高：MetaMathQA 53.7%、orca-math 44%，precision 99.3–99.6%。
